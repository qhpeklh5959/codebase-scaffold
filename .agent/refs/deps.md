# 依赖代码库注册表

本文件由 `/import-dep` 维护，记录当前代码库依赖的外部代码库及其导入状态。

每个依赖的详细符号表存放在 `.agent/refs/deps/{name}/symbols.md`，规范存放在 `.agent/refs/deps/{name}/conventions.md`（若有）。
