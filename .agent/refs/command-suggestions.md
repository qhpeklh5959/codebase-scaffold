# Command 建议清单

本文件由 `/gen-command --suggest`、`/bootstrap`、`/reflect` 自动写入，记录针对当前代码库建议新增的定制 commands。

运行 `/gen-command --create <name>` 将某条建议生成为实际的 command 文件。
运行 `/gen-command --list` 查看所有待处理建议。
