# 参考代码库注册表

本文件由 `/ref-from` 维护，记录当前代码库参考的外部代码库及其导入状态。

参考库与当前库**没有调用关系**，只提供实现模式和架构思路。若需要导入有调用关系的依赖库，使用 `/import-dep`。

每个参考库的详细模式存放在 `.agent/refs/refs/{name}/patterns.md`。
