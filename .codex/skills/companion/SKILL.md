# Accompany implementation

Treat the remaining user request after `$companion` as the task. Follow the detailed workflow in [the legacy workflow](../../../.claude/commands/companion.md). Use `$` skill names in place of any legacy slash names.

Create the plan and checklist before changing implementation files. Keep task status in the task document and record only verified, reusable facts in the knowledge base. When `AGENT-DEVELOPMENT.md` exists, use its self-maintenance mode and keep all companion artifacts in `.agent/self/`.
